# XFCE 图形验证与 GT9886 触摸支持（2026-09-05）

## 结果与边界

XFCE 桌面已在手机屏幕显示，用户确认安装成功。Xorg 使用 DSI-1，
分辨率 1080×2340、60 Hz；Mesa renderer 为 freedreno FD640，
`direct rendering: Yes`、`Accelerated: yes`。

用户随后反馈触摸不可用。运行中的控制 DTB 声明 `goodix,gt9886`，
I²C 设备 `1-005d` 存在但没有驱动绑定；原模块的 OF alias 不匹配它。
补入 GTX8 驱动后，产品 ID 检查和 probe 通过，新增
`Goodix GTX8 Capacitive TouchScreen`（本次为 `/dev/input/event3`），
udev 标记 `ID_INPUT_TOUCHSCREEN=1`，Xorg 已用 libinput 接入。

55 秒事件采集窗口内没有事件，后续 IRQ 计数仍为 0。用户尚未反馈加载后
的点按结果；因此目前是 **驱动绑定和桌面接入通过，实际触摸待验证**。
不能用 input 节点存在来替代点按、滑动、释放、坐标方向及多点验收。

## 桌面安装

手机使用 Debian 13 trixie。安装前模拟 APT 事务，确认没有移除包或更新
Linux/GRUB/U-Boot。此次未修改内核启动参数或系统 APT 源。

可在网络正常的手机上复现安装：

```sh
sudo apt-get update
sudo apt-get install --no-install-recommends \
  xfce4 xfce4-terminal lightdm lightdm-gtk-greeter \
  xserver-xorg-core xserver-xorg-input-libinput libgl1-mesa-dri \
  mesa-utils dbus-x11 dbus-user-session fonts-noto-cjk \
  xauth x11-utils scrot librsvg2-common
```

本次 NCM 没有默认互联网路由，通过 SSH 的远端动态转发临时提供
`127.0.0.1:18080` SOCKS5，APT 用 `socks5h` 远端解析 DNS。
代理只在命令期间存在，TLS 和签名检查保留。安装后已清理 APT 下载缓存，
从 188 MiB 降至 24 KiB。软件包本身保留在 userdata。

版本：XFCE 元包 4.20.1、Xorg 21.1.16、LightDM 1.32.0、
Mesa 25.0.7。XFCE 与 SVG loader 共新增 260 个包。

首次显示使用 `/run/raphael-desktop/lightdm.conf` 和 LightDM 的运行期
systemd drop-in，自动进入 `raphael` 的 XFCE 测试会话。此配置重启后消失；
LightDM 服务本身已启用，下次正常启动显示登录界面。没有配置永久免密登录。
